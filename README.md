# NotOffice

**NotOffice 1.0.4** — бесплатный портативный редактор и просмотрщик документов для Windows 10/11 x64. Локальная работа без подписок, облачных сервисов и обязательной установки Microsoft Office.

Проект написан на Rust с использованием `eframe`/`egui` и распространяется по лицензии MIT.

Сайт: [danilagrinrus.github.io/NotOffice](https://danilagrinrus.github.io/NotOffice/) · [Релизы](https://github.com/DanilaGrinRus/NotOffice/releases) · [Инструкция](USER_GUIDE_RU.md).

## Возможности

- DOCX, TXT, Markdown и простой RTF: просмотр и редактирование.
- XLSX, XLS, XLSB, ODS, CSV и TSV: просмотр таблиц; редактирование с сохранением поддерживаемой XLSX-копии; закрепление верхней строки/левого столбца.
- Legacy DOC: извлечение текста, best-effort просмотр изображений и преобразование в DOCX.
- PDF: просмотр и печать на Windows, без редактирования.
- Поиск и замена, Undo/Redo, независимые окна.
- Безопасное сохранение с обнаружением внешних изменений.
- Recovery-снапшоты и восстановление после сбоя.
- Печать и экспорт в PDF, HTML, TXT и CSV.
- Русский и английский интерфейс, шесть экранных тем.
- Очищенная копия, вставка диапазонов и действия «Недавние».

В 1.0.4 исправлены меню, «Недавние», поиск/замена, ввод и выделение текста,
добавлены Enter-переносы в DOCX и простые формулы/заполнение в XLSX.

Макросы, сценарии и команды документов не выполняются. Простые арифметические формулы в XLSX-правке вычисляются; сложные формулы, функции и диаграммы Excel не воспроизводятся.

## Сборка

Требуется stable Rust с поддержкой Rust 2021.

```powershell
cargo fmt --check
cargo check --all-targets
cargo test --all-targets
cargo clippy --all-targets -- -D warnings
cargo build --release
# Для поставки с очищенными путями:
powershell -File packaging/windows/build-release.ps1
```

Готовый исполняемый файл появится в `target/release/notoffice.exe`.

Запуск с открытием документа:

```powershell
cargo run -- path\to\document.docx
```

Проверки текущих исходников: **253 passed, 9 ignored**, fmt/check/clippy/release PASS.
Многопроцессная запись настроек проверена автоматически; отдельный GUI-прогон

Linux и macOS остаются экспериментальными: доступны исходники и скрипты сборки, но печать и PDF-просмотр реализованы только для Windows. Готового приложения macOS нет.

## Ограничения

NotOffice не является полной заменой Microsoft Office:

- сложная вёрстка, стили, списки и таблицы Word поддерживаются не полностью;
- преобразование DOC в DOCX не гарантирует сохранение исходной структуры;
- формулы и сложные объекты электронных таблиц не воспроизводятся;
- XLSB и ODS ориентированы на просмотр;
- печатная вёрстка приблизительная;
- презентации, OCR и облачная совместная работа не входят в версию 1.0.

Подробнее: [STATUS_RU.md](STATUS_RU.md), [USER_GUIDE_RU.md](USER_GUIDE_RU.md) и [GPT_HANDOFF_RU.md](GPT_HANDOFF_RU.md).

## Структура

- `src/` — исходный код приложения и модулей форматов.
- `tests/` — интеграционные тесты и fixtures.
- `packaging/` — скрипты сборки Windows, Linux и macOS.
- `docs/` — историческая и техническая документация.
- `licenses/` — тексты лицензий зависимостей и шрифтов.
