# NotOffice 1.0.0 — финальный Windows-релиз

Дата: 26.10.2026. Платформа: Windows 10/11 x64.

Принятый кандидат 1.0.0-rc.2 оформлен как 1.0.0. При финализации изменены
версия, пользовательская инструкция, документация и упаковка; поведение
редактора не менялось. Назначение проекта сохранено дословно в README и гайде.

## Возможности

- DOCX/DOC, XLSX/XLS, TXT/MD/RTF; просмотр XLSB/ODS и CSV/TSV, PDF.
- Прямой ввод в текст и ячейки редактируемых копий, поддерживаемое
  форматирование, поиск/замена и Undo/Redo.
- Save/Save As, конфликты нескольких окон, восстановление после сбоя.
- Печать, диапазон и масштаб PDF, экспорт DOCX/XLSX, CSV, текста, HTML/PDF.
- RU/EN, независимые окна, portable EXE без Office и сети.
- Исправленный XLSB: фильтрация листов диаграмм, даты 1900/1904 и длительности.
- Макросы и скрипты документов не исполняются; формулы не вычисляются.

## Приёмка

Ручные проверки восстановления MD/RTF/XLSX, двух окон XLSX, физической печати
и чистого Windows portable подтверждены пользователем. Исторические протоколы
и доказательства кандидатов сохранены без изменения их версии.
Для финальных исходников: 219 тестов PASS, 9 ignored; fmt/check/clippy/release PASS.
Архивы и контрольные суммы обновлены. Внешняя публикация не выполнялась.

## Ограничения

Полное совпадение с Word/Excel не обещается. Сложное оформление DOC и таблиц,
формулы и диаграммы в копиях значений не сохраняются. PDF не редактируется;
печать PDF растровая. Подробности: USER_GUIDE_RU.md и STATUS_RU.md.
Linux/macOS остаются экспериментальными; финальный выпуск принят только
для Windows. Прежние Linux RC-пакеты не переименованы в финальные.

История кандидата: docs/CHANGELOG_1.0.0-rc.2_RU.md.

## Hotfix после релиза (26.10.2026)

- Поле «Заменить на» теперь видно всегда, отдельного переключателя
  «Замена…» / «Скрыть замену» больше нет.
- «Очистить замену» очищает только поле «Заменить на»; поисковый запрос
  не меняется.
- После «Заменить» / «Заменить всё» фокус возвращается в поле замены, чтобы
  можно было сразу заменять следующие совпадения.
- Enter в поле замены теперь работает не только для DOCX, но и для TXT/MD/RTF
  и редактируемых таблиц.
- Логика замены и 219 тестов не менялись по смыслу; обновлены EXE, архивы,
  контрольные суммы.

## UX-пакет (26.10.2026)

- Ctrl+S на защищённой копии (DOC→DOCX, RTF, recovery, новая книга) сначала
  объясняет, почему нужна отдельная копия, и только потом открывает Save As.
- Выделение текста стало тёплым и контрастным.
- «Ширина из документа (%)» больше не обещает глобальный процент: подпись
  объясняет, что ширина берётся из каждого изображения DOCX.
- Печать осталась на панели и Ctrl+P; третья кнопка «Печать» из параметров
  печати убрана.
- Переключатель RU/EN — в правом верхнем углу; рядом кнопка «Масштаб»
  для сброса на 100%.
- Меню «Вид» убрано: масштаб, язык и параметры печати теперь на панели.
- «Правка» переименована в «Правки».
- Из «Файл» убраны дубли Open/Save/Print/Close; «Экспорт текста» называется
  «Экспорт в TXT…».
- DOC→DOCX только через предупреждающий диалог; оригинал .doc не меняется.
- Для TXT/MD/RTF работают поиск/замена, «Выделить всё» и Ctrl+A.
- В полосе нового текстового документа видны «Выделить всё» и «Шрифт»:
  «Выделить всё» активна после появления текста; для TXT/MD/RTF шрифт
  не хранится, поэтому показан поясняющий прочерк.
- Recovery показан компактной точкой: зелёная — включено, жёлтая —
  недоступно; при наведении выводится расширенная подсказка.
- Стартовый масштаб документа — 100%.
- Тесты: 219 PASS, 9 ignored.
