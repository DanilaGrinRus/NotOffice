Кнопка `Edit as DOCX…` переводит восстановленное содержимое DOC в отдельную

DOCX. До сохранения работают dirty/close/open/recovery guards. После Save As
применяется обычная защита DOCX от внешних изменений и конфликта двух окон.

## Матрица поддержки

| Элемент | Результат |
|---|---|
| Восстановленный основной текст, кириллица, XML-символы | Переносится, редактируется |
| Размер шрифта, назначенный в редакторе | Сохраняется в DOCX |
| Абзацы | Переносятся; внутренние переносы строк становятся абзацами |
| Изображения PNG/JPEG | Переносятся; ручные/проверенные привязки учитываются, остальные идут в конец |
| Исходные шрифты/стили, таблицы, списки, поля, колонтитулы | Не восстанавливаются; предупреждение показано до конвертации |
| Макросы, скрипты, встроенные объекты и внешние связи | Не копируются и не исполняются |

Неподдерживаемые элементы не означают полной совместимости с Word. При ошибке
изображения конвертация отклоняется с сохранением прежнего просмотра.
