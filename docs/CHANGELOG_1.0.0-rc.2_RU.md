# NotOffice — 1.0.0-rc.2

Дата: 25.10.2026. База: NotOffice 0.8.0-rc.22, отдельный форк
`C:\NotOffice\NotOffice-1.0.0-rc.2`.

## Новое в RC

### Исправления XLSB после приёмки

- Смешанные книги с диаграммами открываются: импортируются только табличные
  листы, включая скрытые. Ошибки повреждённых табличных листов не скрываются.
- Даты XLSB/XLS отображаются в ISO вместо серийных чисел, с учётом эпохи
  1900/1904 и времени; длительности выводятся как часы:минуты:секунды.
- Добавлены реальные XLSB-фикстуры и 6 регрессионных тестов.

### Защита данных

- Восстановление после сбоя для XLS/XLSX-копий: сессия `Workbook`,
  неизменяемые снапшоты `.loxlsx` с длиной и контрольной суммой, чекпоинт
  каждые 2 секунды, общий диалог восстановления, fallback на предыдущую
  валидную точку, лимиты 64 листа / 250 000 ячеек / 32 МиБ.
- Сохранение книги очищает recovery-сессию и флаг «восстановлено»; после
  успешного Save As копия больше не предлагается.
- Восстановление поднимает листы, значения и форматирование; оригинал
  XLS/XLSX защищён и требует отдельной копии.

### Редактирование

- Undo/Redo для таблиц: значения и форматирование, отдельные стеки, лимит
  100 шагов, Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y.
- Undo/Redo для TXT/MD/RTF с собственной историей текста.
- Замена `current` / `all` для DOCX, таблиц и TXT/MD/RTF; групповая замена —
  одна транзакция Undo, лимит 10 000 совпадений блокирует замену целиком.
- Поиск по текстовым документам и книгам в общей строке Find.

### Экспорт

- **Экспорт PDF** из DOCX и таблиц через «Файл → Экспорт PDF…»; использует
  текущие параметры страницы (ориентация, поля, номера страниц).
- **Экспорт HTML** из DOCX и таблиц (текст/таблицы, без изображений).
- **CSV/TSV импорт** как read-only таблица: кавычки, переводы строк, `;`/`,`/
  табуляция, UTF-8/Windows-1251.
- **ODS и XLSB read-only** через уже подключённый calamine.
- XLSX импортирует числа, TRUE/FALSE и даты (включая числовые даты по стилю
  ячейки).
- XLSX пишет числа (`t="n"`), TRUE/FALSE (`t="b"`) и ISO-даты `YYYY-MM-DD`
  (`t="d"`) типами; текст с ведущими нулями, пробелами и формулами остаётся
  текстом. Шрифт/жирность сохраняются, числовой формат подбирается по типу.

### Интерфейс

- Компактная оболочка: командная строка, строка документа и статус.
- Русский и английский интерфейс, переключение в «Вид → Язык интерфейса»,
  выбор сохраняется в `NotOffice-language.txt`.
- Стартовый экран с недавними файлами; `--blank-text` для пустого окна.
- A4-страница держит реальную ширину и центрируется.
- Векторные иконки, светлая «бумажная» тема, Segoe UI Semibold.

## Известные ограничения

- DOC/DOCX: матрица форматирования неполная (шрифт/кегль и текст; стили,
  списки, сложные таблицы при экспорте сохраняются не полностью).
- DOC → DOCX переносит восстановленный текст и изображения, но не исходные
  стили/структуру таблиц.
- XLS/XLSX: числа, bool и даты распознаются при импорте и сохраняются при
  экспорте; формулы не вычисляются и кеш результата не обновляется.
- Лимиты и поведение на больших/повреждённых файлах, ZIP bombs и ошибках
  записи покрыты частично.
- Ручная регрессия RC: предпросмотр DOCX, системный диалог, PDF view/print,
  два окна, конфликт сохранения, GUI-вывод PDF (`ячм.pdf`) — PASS; физический
  принтер подтверждён пользователем. См. `RC_MANUAL_REGRESSION_RU.md`.
