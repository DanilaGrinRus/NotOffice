Обязательные требования: `MANDATORY_FUNCTIONAL_REQUIREMENTS.md`.
Это первая часть FR-04, а не выполнение всех четырёх требований и не закрытие

## Что реализовано

- Ctrl+F — поиск; Ctrl+H либо `Replace (Ctrl+H)` — строка замены. В поле Find
  Enter/F3 — далее, Shift+Enter/Shift+F3 — назад. Enter в поле замены либо
  `Replace current` заменяет выбранное вхождение. `Replace all` заменяет все
  вхождения документа, включая таблицы. Пустая замена удаляет найденный текст.
- Сопоставление буквальное, без учёта регистра по Unicode lowercase, без regex,
  нормализации и полного case-folding; края запроса обрезаются как в rc.4.
  Поиск не пересекает границы абзацев/ячеек. Подсветка фрагментная, точный
  текущий диапазон виден в нижнем контексте; повторные слова одного фрагмента
  могут иметь общий фон, но разные позиции в счётчике.
- Через границы текстовых фрагментов: вставка получает формат первого
  затронутого run; остальные стили, идентификаторы, абзацы, таблицы, изображения
  и неиспользуемые части ZIP сохраняются. Это не полная Word-совместимость:
  сложные поля/разметка вне импортированной текстовой модели не редактируются
  семантически. Не обещается поиск в колонтитулах/сносках/надписях.
- Каждая замена — одна Undo-транзакция. Undo/Redo кнопками; Ctrl+Z/Ctrl+Y и
  Ctrl+Shift+Z вне toolbar-полей. В Find/Replace/font поле Ctrl+Z работает с
  самим полем, не с документом. Текст поля замены также не перехватывает Ctrl+A
  для массового форматирования документа. Escape в замене закрывает строку.
- Результат сначала полностью проверяется в отдельной модели, затем применяется.
  Нет изменения исходника до Save/Save As. Неизменяющая замена не создаёт dirty
  или Undo. Отказы не применяют половину операции. Save/close/open/conflict и
  существующий recovery-механизм получают обычное изменённое DOCX-состояние.
- Лимит Find — 10 000; при превышении Replace all запрещён, а не урезается.
  Текст замены до 1 MiB, суммарный результат до 32 MiB; ввод многострочных,
  управляющих и недопустимых XML-символов отвергается. Увеличение XML при
  escaping дополнительно проверяет существующий безопасный Save.
- Пустые w:t сохраняют идентификаторы при повторном чтении; новым крайним
  пробелам ставится `xml:space="preserve"`, XML-спецсимволы экранируются.
- Исправлен Ctrl+A / Select all → Delete/Backspace: удаляет выбранный текст
  всего DOCX одной Undo-транзакцией, сохраняя картинки/табличную структуру.
  Обычный Delete в поле удаляет выделение или символ справа, Backspace — слева.
  Автоматически подтверждён дефект общего выделения; для обычного поля тесты
  проходят, нативное пользовательское сообщение остаётся до повторной проверки.
- Данные замены/история принадлежат окну. Замена не исполняет документные данные.
  DOC/XLS/XLSX пока остаются read-only, строка показывает ограничение; PDF
  остаётся растром без текстового поиска/замены и печати.

## Краткая ручная проверка — пока NOT VERIFIED

Новый кандидат: `C:\NotOffice\LiteOffice-v0.8.0-rc.5.exe`.
Тестовый исходник: `manual_phase4_artifacts/replace-rc5/replace.docx`.
Сравнительные файлы: `expected-cats.docx`, `expected-deleted.docx` рядом.
Это синтетические DOCX, не пользовательские документы.

1. Ctrl+H, Find `ёжик`, Replace with `Кот`: три совпадения; перейдите на второе
   и нажмите Replace current — меняется только оно. Проверьте первое слово,
   разбитое на два run, и слово в таблице. Текущий счётчик/контекст обновляются.
2. Undo/Redo, затем Replace all: все слова заменены. Один Undo возвращает всю
   массовую замену. Проверьте также пустую замену и отмену через Undo.
3. Save As в новый `my-replaced.docx`, закрыть/открыть: результат сохранён;
   исходный `replace.docx` не изменён. На несохранённой замене Close/Open →
   Cancel сохраняет правки и окно. Не закрывайте единственную несохранённую
   копию через Don't save, если хотите её сохранить.
4. Один тестовый DOCX откройте в двух окнах. Разные замены в A/B не влияют друг
   на друга. A сохраняет, затем B — конфликт; Cancel оставляет правки B,
   Save a copy сохраняет их отдельно без перезаписи A.
5. Ctrl+A/Ctrl+Z в Find/Replace меняют только поле; Escape закрывает замену.
   В DOC/XLS/XLSX замена недоступна с пояснением, Find продолжает работать.
6. В DOCX выделите мышью несколько букв → Delete, затем Undo. Поставьте курсор
   перед буквой → Delete (убирает справа). Ctrl+A → отпустить Ctrl → Delete:
   весь текст, включая таблицу, очищен; изображение/каркас таблицы остаются.
   Один Undo возвращает всё. Save As/reopen пустого результата проходит без
   потери идентификаторов/ошибки. Повторите Ctrl+A → Backspace.
   Для проверки сохранности картинки используйте отдельную копию
   `manual_phase3_artifacts/phase3_print_fixture.docx`, не перезаписывая оригинал;
   печатать его для этой проверки не нужно.

Это приёмка новой замены, не запуск отложенной полной регрессии печати/recovery.
Нативный GUI, внешний Word cross-open и весь многоконный FR-01–04 gate остаются
NOT VERIFIED до фактической проверки. Принятые старые ручные PASS не заменяют
приёмку новой функции.
