# Документация: читать с оговоркой

Файлы в этом каталоге — **историческая документация апстрима LiteOffice
0.8.0-rc.12** и ранних фаз проекта. Они сохранены для контекста, но их статусы
могут быть устаревшими.

Актуальный статус форка: [../STATUS_RU.md](../STATUS_RU.md).
Изменения финального Windows 1.0: [../CHANGELOG_1.0.0_RU.md](../CHANGELOG_1.0.0_RU.md).
История кандидата: [CHANGELOG_1.0.0-rc.2_RU.md](CHANGELOG_1.0.0-rc.2_RU.md).
Архитектура и правила: [../GPT_HANDOFF_RU.md](../GPT_HANDOFF_RU.md).

В частности, `ROADMAP_TO_1_0_RU.md` и `RELEASE_PROGRESS.md` описывают
**исходный проект**, где Phase 4 остаётся PARTIAL и многих функций форка ещё
нет. Не использовать их как текущий чек-лист NotOffice.

`PHASE4_*.md`, `MANDATORY_FUNCTIONAL_REQUIREMENTS.md`,
`SECURITY_ACTIVE_CONTENT.md`, `V1_0_UX_AUDIT_CRITERIA.md` полезны как
требования/история, но при конфликте с `../STATUS_RU.md` приоритет у
`STATUS_RU.md`.
