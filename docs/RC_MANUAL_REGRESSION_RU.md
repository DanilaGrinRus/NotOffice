## Что именно наблюдалось

### Печать DOCX

- Файл `manual_phase3_artifacts/automated-1792937959209/print-regression.docx`
  открыт в RC. Файл → Печать открыл окно «Предварительный просмотр».
- В предпросмотре видны: «Кириллица: Ёжик. PAGE-ONE», таблица с границами,
  зелёное изображение, подпись «Page 1». См. `manual_rc_regression/docx-print-preview.png`.
- Печать из предпросмотра открыла системный диалог
  «Операционная система Microsoft® Windows® — печать» с уже выбранным
  **Microsoft Print to PDF**. См. `manual_rc_regression/system-print-dialog.png`.
- В моей автоматизации нажатие «Печать» один раз завершилось статусом
  «Печать отменена пользователем»; отдельно пользователь напечатал документ
  через тот же GUI-путь. Предоставленный файл `C:\NotOffice\ячм.pdf`
  создан `Microsoft: Print To PDF`, title — `LiteOffice document (approximate
  layout)`: 2 страницы A4, «Кириллица: Ёжик. PAGE-ONE», таблица, зелёное
  изображение, номера «Page 1»/«Page 2». Это подтверждает сквозной GUI-вывод.
  Копия: `manual_rc_regression/printer-user-print.pdf`, рендеры
  `printer-page-1.png`, `printer-page-2.png`.

## Что осталось непроверенным

- **Физический принтер**: пользователь подтвердил, что печать работает; отдельного
  бумажного задания и скана в этой сессии нет. Инструментально подтверждён
  GUI-вывод в PDF (`ячм.pdf`).
- Сквозной GUI-вывод в PDF подтверждён пользовательским файлом `ячм.pdf`;
  мой автоматизированный сеанс один раз завершился отменой, поэтому
  дополнительно опираюсь на предоставленный артефакт.
- `local_legacy_doc_preview_image_regression` — **PASS** на синтетическом
  `manual_rc_regression/legacy-image-fixture.doc`: валидный Word 97–2003 DOC
  (`export-test.doc`) с добавленным PNG; recovered gallery декодировала и
  нарисовала 1 изображение. Это проверка best-effort gallery, а не
  позиционирования OfficeArt в исходной вёрстке.
- `export_manual_text/find/replace/workbook_fixtures` и
  `export_pdf_reader_evidence` не запускались: они требуют **новых** каталогов
  и по своему контракту отказываются перезаписывать существующие ручные
  артефакты. Это генераторы фикстур, а не регрессионные проверки.
- `render_existing_mixed_pdf_for_reader_qa` — **PASS** на сгенерированном
  `portrait-10mm.pdf`.
