# LiteOffice v0.5.2 — исправление импорта старых DOC (экспериментальный патч)

Этот патч использует исходники LiteOffice v0.5.2 Optimized Release.

## Что изменено

- `src/doc.rs`: извлечение текста из DOC по таблице CLX/PlcPcd вместо сканирования бинарного WordDocument. Порядок и длина текста определяются FIB, используются только символы основного документа, исключаются произвольные байты и метаданные.
- `src/main.rs`: предпросмотр DOC с текстом по левому краю и ограниченной шириной; улучшены переносы строк. DOC остаётся только для просмотра и экспорта в TXT.
- Добавлены тесты синтетической FIB/CLX-структуры и разбиения текста на абзацы.
- Другие форматы (DOCX/XLS/XLSX) не менялись.

## Установка

1. Полностью закрой LiteOffice.
2. Сохрани копии `C:\NotOffice\liteoffice\src\doc.rs` и `src\main.rs`.
3. Скопируй из архива **только** `src\doc.rs` и `src\main.rs` с заменой. НЕ заменяй Cargo.toml и Cargo.lock — настройки оптимизации сохраняются.
4. Открой PowerShell:

```powershell
cd C:\NotOffice\liteoffice
cargo fmt
cargo check
cargo test
cargo build --release
Copy-Item .\target\release\liteoffice.exe C:\NotOffice\LiteOffice-v0.5.2-docfix.exe -Force
```

Если `cargo check` или `cargo test` завершился ошибкой — остановись и пришли полный вывод.

## Проверка

Открой оба DOC: «Анализ ниши Постельное белье.doc» и «Анализ_ниши_Шампуни_после_кератина_бессульфатные_шампуни.doc». Проверь заголовок, список конкурентов и текстовые разделы. В начале не должно быть случайных квадратов / мусорного Unicode, а абзацы должны быть в порядке оригинала.

## Что ещё не реализовано

Этот патч исправляет извлечение текста, а **не полноценный layout бинарного Word**. Изображения, графики, диаграммы, таблицы, стили, интервалы, поля, колонтитулы, сноски пока не воспроизводятся; исходные DOC не редактируются и не сохраняются. Для точного отображения потребуется разбор PAPX/CHPX, OfficeArt, графики и макет страниц.

Ограничения/риски: некоторые повреждённые, зашифрованные или нестандартные DOC будут отклонены вместо восстановления случайных строк. Код не компилировался в этой Linux-среде; сборку на Windows необходимо проверить командами выше.
