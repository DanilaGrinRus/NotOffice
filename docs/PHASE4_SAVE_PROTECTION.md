## Исправлено и добавлено

Два дефекта воспроизведены до исправления отдельными падающими тестами:

1. Второе сохранение собственных изменений блокировалось как внешнее изменение:
   после первого Save не обновлялась контрольная версия исходного DOCX.
2. Сохранение копии после внешней замены файла смешивало старый редактируемый XML
   с новыми изображениями/связями/другими частями пакета с диска.

Исправление сохраняет ограниченный по размеру снимок открытого пакета в памяти.
Запись остаётся через проверенный временный DOCX и атомарную замену с резервной
копией. Save обновляет текущий путь/контрольную версию только после успеха;
Save As переводит дальнейшие Save на выбранную копию. Ошибка оставляет модель и
dirty-состояние в окне. Снимок не является автоматическим восстановлением после
сбоя и не записывается на диск в фоне.

Добавлены обычный Save, отдельный Save As, Ctrl+Shift+S и Ctrl+O. Открытие другого
документа и закрытие окна при несохранённых правках показывают Save / Don't save /
Cancel. Внешнее изменение вызывает выбор Save a copy / Reload from disk (discard
my edits) / Cancel. Неудачная загрузка внешнего файла сохраняет текущие правки.
