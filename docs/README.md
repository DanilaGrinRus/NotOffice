# LiteOffice v0.5

Небольшой Windows-редактор DOCX и просмотрщик Excel на Rust. Версия 0.5 добавляет отдельную модель текстовых фрагментов OOXML, отображение листа A4 с физическими полями и осторожное сохранение изменённого документа.

## Что поддержано

- открытие DOCX как ZIP-пакета;
- открытие XLSX-вкладок в виде таблицы, включая общие строки, числа, логические значения и inline-строки;
- открытие XLSX и XLS со всеми доступными вкладками; переключение листов и экспорт выбранного листа в CSV;
- базовый импорт незашифрованного Word 97–2003 DOC: восстановленный текст доступен для просмотра и экспорта;
- чтение абзацев `w:p` и редактируемых фрагментов `w:t` в исходном порядке;
- отображение простых OOXML-таблиц по строкам и ячейкам с переносом строк таблицы на новый лист;
- редактирование отдельных текстовых фрагментов в интерфейсе;
- постраничный просмотр A4 210 × 297 мм с полями 20 мм и масштабом 50–180 %;
- сохранение в новый DOCX: все ZIP-части, кроме `word/document.xml`, копируются без интерпретации;
- изменяется только содержимое узлов `w:t`; XML экранируется библиотекой;
- перед заменой существующего файла создаётся `<имя>.docx.bak`; при ошибке исходный документ не удаляется.
- экспорт доступного содержимого открытого файла в TXT.
- поиск с подсветкой совпадений и переходом между ними в DOCX;
- Undo/Redo для последних 100 DOCX-изменений в текущем сеансе;
- перетаскивание файла в окно, предупреждение о несохранённых DOCX-изменениях и список последних восьми файлов.

## Ограничения этой версии

Это ещё не полноформатный Word-совместимый движок. Интерфейс не воспроизводит шрифты, объединение ячеек, границы и ширины таблиц, колонтитулы, изображения и переносы точно как Microsoft Word. Простые таблицы отображаются с визуальными границами ячеек. Разбиение на листы — визуальная оценка по высоте текстовых фрагментов, а не точная пагинация Word. Такие части остаются в пакете при сохранении, но не отображаются и не редактируются.

Фрагменты без текстового события (например, пустой `w:t`) в v0.5 не становятся редактируемыми. Документы с нестандартной разметкой, где `w:t` находится вне `w:p`, отклоняются безопасно.

XLSX и XLS пока открываются только для безопасного просмотра: редактирования, сохранения, вычисления формул и точного воспроизведения стилей нет. Переключение листов и экспорт выбранного листа в CSV доступны. Для ячеек с формулами может быть показано последнее сохранённое Excel значение.

DOC — это только режим восстановления текста: файлы с шифрованием не открываются, сложная структура, таблицы, изображения и исходное форматирование не сохраняются. Редактирование и сохранение в DOC недоступны.

## Сборка и запуск в Windows

Установите stable Rust через rustup, затем в этой папке выполните:

```powershell
cargo test
cargo run --release
```

Приложение открывает DOCX, DOC, XLSX или XLS через системное окно выбора. Кнопка сохранения доступна только для DOCX. Для остальных форматов доступен экспорт в TXT. Для сохранения DOCX выбирайте отдельное имя; при перезаписи рядом появится резервная копия с расширением `.docx.bak`.

## Тесты

`cargo test` проверяет:

1. физическую геометрию A4;
2. порядок текстовых фрагментов в XML;
3. экранирование нового текста и сохранение XML-атрибутов;
4. round-trip ZIP/DOCX: сохранность посторонней части пакета и создание резервной копии.
5. открытие первой вкладки XLSX со shared strings, числами и логическими значениями.
6. извлечение UTF-16 текста из незашифрованного DOC.
