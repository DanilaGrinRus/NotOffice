# NotOffice 1.0.4 — инструкция пользователя

## Для чего нужен NotOffice

> Для тех кто заебался от вечных подписок на самые базовые функции работы с самыми популярными форматами документов, полностью бесплатно, навайбкожено, быстрый и легкий клиент, наслаждайтесь

NotOffice — бесплатная программа для локальной работы с документами, простыми
таблицами, текстом и PDF. Финальный выпуск 1.0 предназначен для Windows 10/11 x64.
Для работы не нужны Office, LibreOffice, Python, учётная запись или интернет.
Документы не отправляются в облако.

## Первый запуск

1. Распакуйте NotOffice-1.0.4-portable.zip в отдельную папку с правом записи,
   например в «Документы». Не запускайте программу непосредственно из архива.
2. Запустите NotOffice-1.0.4.exe. Установка не требуется.
3. Нажмите «Открыть документ…» и выберите файл либо перетащите его на окно.
   Кнопка «Новый текст» создаёт пустой TXT и открывает редактор для ввода.

Без аргументов EXE показывает стартовый экран и недавние файлы. Документ можно
передать аргументом запуска или открыть через «Открыть с помощью» в Проводнике.
Распаковка не привязывает расширения к NotOffice автоматически.

Настройки, недавние файлы и NotOffice-recovery хранятся рядом с EXE. Выбирайте
папку с правом записи, а не Program Files. Для переноса можно скопировать
папку программы целиком. Не удаляйте NotOffice-recovery, пока там есть нужные
несохранённые документы.

## Поддерживаемые файлы

| Формат | Возможности |
|---|---|
| DOCX | Просмотр, правка текста и поддерживаемого форматирования, сохранение DOCX, печать |
| DOC | Просмотр восстановленного текста и изображений; преобразование в редактируемую DOCX-копию |
| XLSX / XLS | Просмотр листов, правка копии значений прямо в ячейках, сохранение XLSX |
| XLSB / ODS | Просмотр табличных листов; исходный формат не перезаписывается; «Изменить значения» создаёт XLSX-копию |
| CSV / TSV | Просмотр таблицы, экспорт CSV; «Изменить значения» позволяет создать XLSX-копию |
| TXT | Создание и редактирование обычного текста |
| MD | Редактирование исходного Markdown-текста без оформления как веб-страницы |
| RTF | Чтение текста, правка и сохранение простой копии без сложного оформления |
| PDF | Постраничный просмотр, масштабирование и печать; редактирования нет |

Файлы с паролем могут не открыться. Макросы, встроенные скрипты, команды
документов и PDF-действия не исполняются. Формулы таблиц не вычисляются.

## Открытие и несколько окон

- Кнопка папки на верхней панели или Ctrl+O заменяет документ в текущем окне.
- «Файл → Открыть в новом окне…» открывает независимое окно.
- «Файл → Новый документ» или Ctrl+N открывает новое окно с пустым
  TXT-редактором; «Новый текст» на стартовом экране делает то же самое.
- Кнопка папки или Ctrl+O заменяет документ в текущем окне.
- Shift при перетаскивании файла открывает его в новом окне.
- Недавние файлы доступны на стартовом экране, кнопкой «Недавние» на верхней
  панели и через «Файл → Недавние»; выбор открывает документ в новом окне.

У каждого окна собственные правки, поиск и история отмены. Перед закрытием
или открытием другого файла с несохранёнными правками программа предлагает
сохранить, отбросить изменения или отменить действие. Отмена оставляет документ.

## Недавние файлы и очищенная копия

В панели команд рядом с «Недавние» находится кнопка
**«Сохранить очищенную копию»** — та же функция очистки, отдельная от исходника.

В меню «Недавние» (в панели и в «Файл») есть:

- **«Очистить список недавних файлов»** — спрашивает «Да/Нет»; сами файлы на
  диске не удаляются;
- **«Открыть папку восстановления»** — открывает локальную папку
  `NotOffice-recovery`;
- **«Удалить папки восстановления»** — после подтверждения удаляет закрытые
  сеансы. Активные окна пропускаются; сам документ не меняется.

Пустые каталоги закрытых сеансов удаляются автоматически при запуске.

## Текстовые документы

В DOCX щёлкните по тексту и вводите изменения. Двойной щелчок выделяет слово,
Ctrl+A — весь текст, работают Delete и Backspace. Enter создаёт новую строку
внутри абзаца; перенос сохраняется при сохранении DOCX. Кнопки форматирования применяют доступные
настройки шрифта и кегля. Масштаб окна меняет только просмотр.

Для старого DOC в полосе документа написано «DOC — только просмотр».
Нажмите «Редактировать как DOCX…» или дважды щёлкните по странице DOC.
Появится подтверждение; после него внесите правки и сохраните
копию с расширением .docx. Исходный DOC останется прежним. Переносятся
восстановленное содержимое и доступные изображения; стили и структура сложных
таблиц DOC полностью не сохраняются.

TXT и MD редактируются как обычный текст. RTF поддерживается на базовом уровне:
текст и переносы, без сложной вёрстки и вложенных объектов. Импортированный RTF
сохраняется отдельной копией. В TXT/MD/RTF доступны поиск, замена, «Выделить всё»
и Ctrl+A; шрифт для этих форматов не хранится, поэтому кегль доступен только в DOCX.

## Таблицы

1. Откройте книгу и выберите лист в списке над таблицей.
2. Нажмите «Изменить значения». Программа создаст редактируемую копию данных.
3. Щёлкните по ячейке, в том числе пустой, и вводите непосредственно в ней.
4. Tab / Shift+Tab перемещает по столбцам, Enter / Shift+Enter — по строкам.
5. Над сеткой доступны поддерживаемое форматирование, кегль и жирность.
6. Ctrl+S предложит сохранить копию в .xlsx. После сохранения откройте результат
   и убедитесь, что нужные значения и оформление на месте.

Числа, логические значения и распознанные даты сохраняются поддерживаемыми
типами. Строка 007 остаётся текстом. В XLSB даты показываются в ISO-виде,
например 2021-01-01, а длительности могут превышать 24 часа. В список попадают
табличные листы, включая скрытые; листы диаграмм не отображаются.

Копия значений не сохраняет формулы: используются прочитанные значения/кеши,
которые могут быть устаревшими. Диаграммы, сводные таблицы, сложные стили,
объединения и исходная вёрстка книги не гарантируются. Храните оригинал,
если эти возможности важны для документа.

### Дополнительные действия с таблицей

В редактируемой XLSX-копии:

- кнопки **◀ / ▶** сдвигают видимую область таблицы влево/вправо;
- щелчок по номеру строки или букве столбца выделяет строку/столбец;
- строка **«Формула»** принимает `=A1+B1`, `+`, `−`, `*`, `/`, скобки и ссылки
  на ячейки. Нажмите `=`, чтобы вычислить. Обычная ячейка с `=` остаётся
  текстом; результат вычисления записывается как значение и отменяется одной
  операцией Undo;
- **«Знаков после запятой»** (0–6 или «Авто») меняет только отображение чисел,
  не округляя сохранённые значения.

Формула не сохраняется как формула: в файл попадает результат. Для сложных
расчётов используйте Excel или специализированный редактор.

## Темы оформления

В меню **«Вид → Тема»** доступны шесть вариантов: Светлая, Тёмно-синяя,
Пергамент, Шалфей, Тёплый графит и Янтарный терминал. Выбор применяется сразу
и сохраняется в `NotOffice-settings.txt` рядом с EXE; при следующем запуске
тема восстанавливается. Новые окна используют сохранённый выбор, уже открытые
сохраняют свою тему до переключения в них.

Каждое окно сохраняет только изменённые настройки: изменение масштаба или
печати не отменяет тему, выбранную другим окном. Если два окна меняют один
параметр, для новых окон используется последняя успешно сохранённая правка.
Рядом с настройками может оставаться служебный файл NotOffice-settings.txt.lock;
не удаляйте его при работающем приложении. При сообщении о занятой настройке
повторите изменение после завершения операции в другом окне.

Тема меняет только интерфейс: меню, кнопки, поля, поиск, предупреждения и
выделение. Документ, его цвета, изображения, сохранённые файлы, печать и PDF
не меняются. Для DOCX/XLSX/PDF страница сохраняет исходные цвета; обычный
текст без явных цветов использует фон и текст темы. Переключение не создаёт
несохранённых изменений, Undo или точки восстановления. Повреждённая настройка
возвращает Светлую тему.

Темы — только оформление, не лечение и не гарантия защиты зрения.

### Вставка диапазона

В редактируемой XLSX-копии нажмите **«Вставить диапазон»** — текст из буфера
обмена вставится значениями, начиная с активной ячейки. Поддерживаются
табуляции, CRLF/LF, пустые ячейки и завершающие разделители. Оформление не
переносится; строки с `=` остаются текстом. Ограничения: 4 МиБ, 10 000 строк,
1 000 столбцов, 100 000 ячеек. При превышении не меняется ничего. Вставка —
одна операция Undo/Redo. Обычная вставка внутри редактора ячейки работает как
раньше. Read-only исходник сначала нужно открыть как редактируемую копию.

## Поиск, замена и отмена

Поля «Найти» и «Заменить на» видны постоянно при открытом документе; Ctrl+F
переводит фокус в поиск.
Введите текст и переходите между совпадениями кнопками со стрелками; рядом
показан счётчик. Ctrl+H сразу открывает замену. «Заменить» меняет текущее
совпадение, «Заменить всё» — все. «Очистить замену» очищает только поле
«Заменить на», поисковый запрос не трогает.

Замена доступна для DOCX, TXT/MD/RTF и редактируемых копий таблиц; PDF не редактируется.
При превышении лимита 10 000 совпадений массовая замена блокируется целиком.

Ctrl+Z отменяет действие, Ctrl+Y или Ctrl+Shift+Z возвращает его.
В поле «Заменить на» Ctrl+Z также отменяет последнюю правку документа.
«Заменить всё» отменяется одним действием. История ограничена 100 шагами
и не заменяет сохранение файла.

## Сохранение и защита правок

Ctrl+S сохраняет обычный открытый DOCX/TXT/MD на месте. Для нового документа,
импортированной копии DOC/RTF, копии таблицы или восстановленного сеанса
появляется объяснение, что оригинал защищён и будет создана отдельная копия;
затем открывается выбор файла. Ctrl+Shift+S всегда позволяет выбрать другое имя и папку.

Обычный открытый DOCX, TXT или MD может сохраняться в текущий файл. Чтобы
сохранить оригинал, сначала сделайте «Сохранить как…» под другим именем.
После успешного сохранения отметка несохранённых изменений исчезает.

При ошибке записи правки остаются в окне: выберите доступную папку и повторите.
Если тот же файл изменён другим окном или программой, появляется
«Документ изменён на диске». Можно сохранить свои правки отдельной копией,
перезагрузить записанную версию с отказом от своих изменений или нажать
«Отмена», чтобы оставить правки в окне.

## Печать и PDF

Для DOCX и таблицы откройте «Параметры печати» (иконка на верхней панели):
задайте ориентацию, поля печати, номера страниц и параметры изображений.
Ctrl+P или кнопка принтера на панели открывает системный предпросмотр.
Выберите устройство и при необходимости поставьте в предпросмотре Windows
масштаб 100% — сам NotOffice этим окном не управляет.

«Файл → Экспорт PDF…» сохраняет печатный результат DOCX или таблицы через
Microsoft Print to PDF. Этот принтер должен быть доступен в Windows.
Экспорт использует текущие параметры страницы.

Для печати готового PDF сначала откройте его. В диалоге печати задайте диапазон
страниц, вписывание или масштаб, затем выберите принтер. PDF печатается
растровыми страницами: при большом увеличении чёткость может снижаться.
Вёрстка DOCX приблизительная и может отличаться от Word.

Отмена печати не меняет документ. Пока системный диалог печати открыт, повторный запуск
печати блокируется сообщением; закройте диалог или дождитесь завершения.
При ошибке проверьте принтер, очередь, подключение и диапазон; несохранённые
правки остаются в окне.

## Копия без активного содержимого

Для DOC/DOCX и XLS/XLSX доступна команда
**«Файл → Создать копию без активного содержимого…»**. Она создаёт отдельную
копию `-clean.docx` или `-clean.xlsx`; оригинал не изменяется.

Переносятся только текст, поддерживаемое пассивное форматирование, таблицы,
значения ячеек и проверенные растровые изображения. Формулы (остаются только
сохранённые кеши), макросы/VBA, ActiveX/OLE, вложения, внешние подключения,
связанные шаблоны, поля, гиперссылки и часть оформления теряются. Строки,
начинающиеся с `=`, сохраняются как текст. Кеш значений формул может быть
устаревшим.

Перед сохранением показывается предупреждение. Отмена или ошибка не меняют
открытый документ, его несохранённые правки и исходный файл. Это **не
антивирус** и не гарантия отсутствия любых возможных угроз.

## Другие варианты экспорта

В меню «Файл» доступны команды для текущего типа документа:

- «Экспорт в TXT…» — текстовое содержимое.
- «Экспорт CSV…» — данные текущего листа.
- «Экспорт HTML…» — текст и таблицы DOCX/книги без изображений.
- «Сохранить разметку DOC…» — параметры размещения изображений в отдельном
  файле .lo-layout рядом с DOC; сам DOC не изменяется.

## Восстановление после сбоя

Для правок DOCX, TXT/MD/RTF и редактируемых копий таблиц программа примерно
раз в две секунды пытается записать контрольную точку. Рядом с именем текстового
документа есть точка: зелёная — восстановление включено, жёлтая — недоступно
(наведите мышь для подсказки). Она не заменяет Ctrl+S:
последние изменения до записи точки могут потеряться.

После аварийного завершения снова запустите EXE из той же папки. Выберите
сеанс в диалоге восстановления и нажмите «Восстановить несохранённую копию».
Проверьте содержимое и сразу сохраните под новым именем. Если имя в диалоге
указано без расширения, NotOffice добавит его сам (TXT/MD/RTF, DOCX или XLSX).
Исходник восстановление не перезаписывает; живые окна не предлагаются.

«Позже» оставляет точки на будущее. Удаление выбранного восстановления
отбрасывает его. После успешного сохранения восстановленной копии сеанс
очищается. При сообщении об ошибке контрольной точки сохраните файл вручную.

## Клавиши, язык и масштаб

| Действие | Клавиши |
|---|---|
| Открыть / новое окно | Ctrl+O / Ctrl+N |
| Сохранить / сохранить как | Ctrl+S / Ctrl+Shift+S |
| Найти / заменить | Ctrl+F / Ctrl+H |
| Выделить всё в редакторе | Ctrl+A |
| Отменить / повторить | Ctrl+Z / Ctrl+Y или Ctrl+Shift+Z |
| Печать | Ctrl+P |
| Закрыть окно | Alt+F4 |
| Масштаб просмотра | Ctrl + колесо мыши или кнопки − / + |

Язык переключается кнопками **RU / EN** в правом верхнем углу. Выбор
запоминается для новых окон; уже открытые могут остаться на прежнем языке.
Масштаб — кнопки − / + справа сверху; кнопка «Масштаб» сбрасывает на 100%.
Стартовый масштаб документа — 100%.

## Ограничения и решение проблем

Если файл не открывается, проверьте расширение и попробуйте заведомо исправный.
Причиной могут быть повреждение, пароль, неподдерживаемые особенности или
превышение защитных лимитов. Переименование расширения не преобразует формат.

Полная совместимость с Office, редактирование PDF, OCR, презентации и облачная
совместная работа в 1.0 не входят. Для важных документов сохраняйте оригиналы
и проверяйте результат преобразования.

Linux/macOS остаются экспериментальными: это не финальные платформы 1.0,
печать и просмотр PDF там недоступны. Подробности — PORTABILITY_RU.md.
