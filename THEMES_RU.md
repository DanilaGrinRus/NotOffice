# Темы оформления — NotOffice 1.2.0

## Шесть тем

| Тема | Фон | Основной текст |
|---|---|---|
| Светлая / Light (по умолчанию) | `#EEEBE4` | `#25231F` |
| Тёмно-синяя / Dark blue | `#152238` | `#E6EDF7` |
| Пергамент / Parchment | `#F3E8D1` | `#40362B` |
| Шалфей / Sage | `#E5ECE0` | `#28382C` |
| Тёплый графит / Warm graphite | `#292624` | `#E8E0D5` |
| Янтарный терминал / Amber terminal | `#211A12` | `#E7BD78` |

Светлая тема использует существующую палитру NotOffice с фоном `#EEEBE4`. Тема меняет
оформление интерфейса, кнопок, полей, меню, выделения, поиска и служебных
сообщений.

## Переключение и сохранение

- **Вид → Тема** — выбор применяется сразу, без перезапуска.
- Выбор хранится в `NotOffice-settings.txt` рядом с EXE вместе с остальными
  настройками.
- Новое окно читает сохранённый выбор; уже открытые окна сохраняют свою тему
  до переключения в них.
- Повреждённая, отсутствующая или неизвестная запись темы даёт **Светлую**
  тему, не остальные настройки.
- Сохранение темы не сбрасывает параметры страницы, печати и масштаб.

## Тема и документ

Тема — только экранное оформление. Она не меняет модель документа, текст,
цвета автора, изображения, сохранённые файлы, экспорт, печать и PDF. Для
DOCX/XLSX/PDF страница сохраняет исходное отображение; интерфейс вокруг неё
меняется. Для обычного текста без явных цветов используется фон/текст темы.
Переключение темы не создаёт dirty-флаг, шаг Undo или точку восстановления.

## Ограничения

- Темы не являются лечением, медицинской рекомендацией или гарантией защиты
  зрения. Это только выбор цветового оформления.
- Контраст основного текста и полей проверяется тестом (не ниже 4,5:1), но
  пользовательские изображения и авторские цвета не перекрашиваются.
- Linux/macOS остаются экспериментальными.
