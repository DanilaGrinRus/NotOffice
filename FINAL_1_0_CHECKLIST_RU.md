# Приёмка Windows 1.0 — завершена

Пользователь подтвердил завершение всех оставшихся ручных пунктов
на принятом Windows-кандидате перед финализацией:

1. Recovery MD/RTF/XLSX: контрольная точка, kill, восстановление, Save As,
   сохранность правок и неизменность оригинала — PASS (сообщение пользователя).
2. Два окна XLSX: живая сессия не предлагается, конфликт блокирует перезапись,
   Cancel оставляет правки — PASS (сообщение пользователя).
3. XLSB: смешанная книга, список табличных листов, ISO-даты и длительность —
   PASS в настоящем окне release EXE; кириллица и повреждённый лист — автотесты.
4. Физическая печать DOCX/PDF, диапазон, отмена, недоступный принтер —
   PASS (сообщение пользователя).
5. Portable на чистом Windows без Office и сети — PASS (сообщение пользователя).

Финализация в 1.0.0 меняет только версию, документацию и упаковку. Для финальных
исходников повторены проверки; исторические скриншоты относятся к кандидатам.
Полный ручной прогон не выдаётся за заново выполненный на финальном EXE.

Windows 1.0 принят в пределах USER_GUIDE_RU.md и опубликованных ограничений.
Linux/macOS остаются экспериментальными. Их приёмка не входит в Windows 1.0.
