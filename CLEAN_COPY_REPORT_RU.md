# Отчёт: копия без активного содержимого — 1.1.0

Дата: 29.10.2026. Windows 10/11 x64.

## Что реализовано

- `src/clean_copy.rs`: сборка нового DOCX из пассивной модели и values-only
  XLSX через существующий защищённый writer.
- Команда **«Файл → Создать копию без активного содержимого…»** для
  DOC/DOCX/XLS/XLSX.
- Предупреждение о потерях, суффикс `-clean`, запрет записи поверх исходника
  (включая hard link/алиас), временная запись, повторное открытие и проверка
  разрешённых частей/отношений.
- Отмена/ошибка не меняют документ, его правки и исходник.
- Исходники найдены не в `C:\LiteOffice` (такого каталога нет), а в актуальном
  `C:\NotOffice`; принятый 1.0.0 сохранён в `accepted-windows-1.0-backup`.
- Новые тесты: текст/кириллица, таблицы, изображение PNG, формулы-строки,
  даты, активные части/внешние связи, неподдерживаемый SVG, hard link,
  values-only XLSX.

## Что теряется

DOCX: макросы/VBA/WordBasic, ActiveX/OLE, вложения, внешние связи, поля,
DDE, гиперссылки, колонтитулы, сноски, примечания, отслеживаемые правки,
стили и часть оформления; переносятся текст, поддерживаемый кегль,
выравнивание, таблицы, разрывы и перекодированные PNG/JPEG.

XLSX: формулы (остаются только сохранённые кеши, возможно устаревшие),
внешние ссылки, макросы, XLM, OLE/ActiveX, диаграммы, изображения, сложные
стили; переносятся значения, листы, размер/жирность, числа/bool/даты.
Строки, начинающиеся с `=`, остаются текстом.

Функция **не является антивирусом** и не гарантирует отсутствие любых
возможных угроз.

## Ограничения

- Linux/macOS экспериментальные; функция проверялась только на Windows.
- DOC/DOCX-совместимость ограничена моделью NotOffice (кегль/выравнивание/
  таблицы). Сложные стили и точная вёрстка не сохраняются.
- Кеш формул XLSX не пересчитывается.
- Отдельный автоматический тест независимых окон для этой команды не добавлен;
  состояние команды локально для каждого `NotOfficeApp`.
- Системные диалоги подтверждения/выбора пути требуют ручной приёмки.
