# NotOffice 1.3.0 — вставка диапазона и быстрые действия

Дата: 29.10.2026. Windows 10/11 x64. Linux/macOS — экспериментальные.
Версии 1.0.0, 1.1.0 и 1.2.0 сохранены отдельно; их файлы не перезаписываются.

## Новое

- Кнопка **«Сохранить очищенную копию»** рядом с «Недавние» в панели команд.
- В меню «Недавние»:
  - **«Очистить список недавних файлов»** с диалогом Да/Нет; документы на
    диске не удаляются;
  - **«Открыть папку восстановления»**.
- В редактируемой XLSX-копии — **«Вставить диапазон»**:
  - активная ячейка становится верхним левым углом;
  - поддержка TSV, CRLF/LF, пустых ячеек, завершающих разделителей и
    кавычек Excel;
  - только значения, без переноса оформления;
  - строки с `=` остаются текстом;
  - проверка лимитов до первой записи, отказ целиком;
  - одна операция Undo/Redo;
  - read-only исходник не изменяется.
- Буфер обмена читается только по явной кнопке, не в фоне.
- Нормальная вставка внутри редактора ячейки не перехватывается.
