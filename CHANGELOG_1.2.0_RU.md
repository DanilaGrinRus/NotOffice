# NotOffice 1.2.0 — темы оформления

Дата: 29.10.2026. Windows 10/11 x64. Linux/macOS — экспериментальные.
Принятый Windows 1.0.0 сохранён для отката; 1.1.0 не перезаписывается.

## Новое

- **Вид → Тема**: Светлая, Тёмно-синяя, Пергамент, Шалфей, Тёплый графит,
  Янтарный терминал.
- Мгновенное переключение без перезапуска.
- Выбор сохраняется в `NotOffice-settings.txt` рядом с EXE и
  восстанавливается при следующем запуске.
- Новые окна берут сохранённую тему; уже открытые окна сохраняют свою.
- Повреждённая/неизвестная настройка безопасно даёт Светлую тему.
- Тёмные палитры применяются к меню, кнопкам, полям ввода, рамкам, выделению,
  поиску, предупреждениям и неактивным элементам.
- Для DOCX/XLSX/PDF страница сохраняет исходное отображение; тема меняет
  окружающий интерфейс. Обычный текст без явных цветов использует фон/текст
  темы.

## Чего тема не делает

- Не меняет модель, текст, авторские цвета, изображения, стили.
- Не помечает документ изменённым, не создаёт Undo/точку восстановления.
- Не влияет на сохранение, экспорт, печать и итоговый PDF.
- Не перекрашивает PDF и растровые изображения.
- Не является лечением или гарантией защиты зрения.
