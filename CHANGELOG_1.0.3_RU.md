# NotOffice 1.0.3 — правки интерфейса и восстановления

Дата: 30.10.2026. Windows 10/11 x64. Linux/macOS — экспериментальные.

- Убраны пункты «Файл → Открыть…» и «Открыть с помощью…»; открытие остаётся
  на кнопке папки и `Ctrl+O`, «Открыть в новом окне…» остаётся.
- Недавние файлы открываются в отдельном окне.
- В «Недавних» добавлено **«Удалить папки восстановления»** с подтверждением.
- Пустые session-каталоги восстановления автоматически удаляются при запуске;
  закрытые сессии очищаются после сохранения/явного отказа. Остаётся один
  корневой `NotOffice-recovery`, без десятков пустых папок.
- Find и Replace видны по умолчанию.
- `Ctrl+Z` в поле «Заменить на» отменяет последнюю правку документа.
- Enter в редактируемом фрагменте DOCX больше не завершает ввод.
- Ширина inline-полей стабилизирована, чтобы текст не дёргался при наборе.
- Двойной клик по слову выделяет слово, а не всю строку.
- Выделение сделано единым насыщенным тёплым цветом.
- Строка действий замены сокращена до двух выровненных кнопок; длинная
  подсказка и «Готово» больше не сдвигают и не обрезают строку.
